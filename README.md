# Space — Route assignment

Flutter source project with Android, iOS, and web runners generated by the official Flutter CLI.

## Run

Flutter 3.50 / Dart 3.14 or a compatible newer stable release:

```bash
flutter pub get
flutter run
```

Web: `flutter run -d chrome`.

## Included

- Introduction, solar-system carousel, and body details.
- Sun and eight planets; swipe or use previous/next controls, then open details.
- Original PNG images and locally bundled GLB models.
- Bundled Roboto fonts with their original license in `assets/fonts/`.
- Interactive 3D rotation/zoom, with an image view available on every detail page.
- Source spreadsheet snapshot in `assets/data/source_sheet.json`; application data in `assets/data/planets.json`.

The 3D viewer needs WebGL / a recent Android System WebView. Its JavaScript is bundled by `model_viewer_plus`; no CDN or remote model fetch is used. Android permits HTTP only to localhost and 127.0.0.1 for the package's local asset server. Android minimum SDK is 24.

## Source references and accuracy

- [Provided Figma design](https://www.figma.com/design/Fn1sGmsLXlWfSdl4p6efja/Space?node-id=56-2)
- [Solar System Data](https://docs.google.com/spreadsheets/d/1orEbD314Q0TBNlGAtd1f6ja0JFLhuwgjDVe2wJvcFNQ/edit?usp=sharing)
- [Original images](https://drive.google.com/drive/folders/1ML10696KQqIQnLRSlPcgDUXz7MK8we0N?usp=sharing)
- [Original 3D models](https://drive.google.com/drive/folders/1E7hKdU_YoHArHOQRZPBAMyib07oOIMa5?usp=sharing)

Figma layer access was denied, and the cloud browser could not render the file because WebGL was unavailable. The layout is a reconstruction using the supplied assets and data; exact Figma measurements and visual fidelity have **not** been verified.

Data corrections are explicit: Mercury's copied Sun paragraph was replaced using [NASA Mercury Facts](https://science.nasa.gov/mercury/facts/). The supplied day values describe rotation periods, so the label is “Rotation period,” consistent with [NASA's Mercury fact sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/mercuryfact.html). The Sun's rotation is 25–36 days and its orbital period around itself is not applicable ([NASA Sun Facts](https://science.nasa.gov/sun/facts/)). Surface areas are spherical approximations, `4πr²`, calculated from the supplied mean radii, correcting the inconsistent exponents in the original sheet. Other numerical fields are retained from that sheet.

Sun, Mercury, Mars, and Neptune used a legacy material extension unsupported by the current viewer. Their materials were converted with the official [glTF Transform `metalrough`](https://gltf-transform.dev/modules/functions/functions/metalRough) command, version 4.5.1. Geometry and texture assets are retained; no mesh simplification was applied.

## Checks

```bash
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

Tests cover the catalog/assets and the introduction → carousel → detail → back flow, including navigation across the carousel boundary on a small screen. Android/iOS device execution and native 3D rendering need a device or emulator; a web build alone does not establish those results.

## Recorded demonstration

[demo.mp4](demo.mp4) is a 45-second automated Flutter UI test session, encoded as H.264 at 12 fps. Its 540 frames come from the actual Flutter engine while the test opens the carousel, reads Earth and Mars details, scrolls their facts, returns, and advances to Jupiter. The recording caption identifies the test environment.

This is not a device or emulator capture, and it does not demonstrate 3D or WebGL rendering. The demonstration uses the app's original local images and data.

To capture the Flutter frames again:

```bash
flutter test tool/record_demo_test.dart
```

The script writes PNG frames and an interaction timeline under `tmp/`. These temporary files are excluded from version control. The included MP4 was also checked with a complete video decode.
